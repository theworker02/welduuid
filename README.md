# welduuid

Weld structured JSON uuid payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/welduuid/

## Install / run

```bash
git clone https://github.com/theworker02/welduuid.git
cd welduuid
node src/cli.js
node --test
```
